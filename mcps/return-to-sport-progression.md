Calculates personalized athletic recovery timelines and phase advancement criteria.

## Description
This MCP server provides decision support for athletic recovery. It connects AI agents to specialized logic that calculates recovery roadmaps using `calculate_progression_plan`, evaluates readiness to move between recovery stages with `evaluate_phase_advancement`, assesses the probability of secondary injury via `assess_reinjury_risk`, and identifies necessary physical assessments through `get_testing_requirements`.


## Available Tools (4)
- **assess_reinjury_risk**: Calculates a qualitative and quantitative risk assessment for the athlete
- **calculate_progression_plan**: Generates the complete structured roadmap for an athlete's return to sport
- **evaluate_phase_advancement**: Determines if an athlete is ready to move from their current phase to the next
- **get_testing_requirements**: Retrieves the specific physical tests required for a given phase and sport

## ❓ FAQ

**Q: How does the tool determine the recovery timeline?**
The timeline is generated by `calculate_progression_plan`, which analyzes the intersection of the specific injury type and the current biological healing stage.

**Q: Can I check if an athlete is ready for the next phase?**
Yes, you can use `evaluate_phase_advancement` to check if current functional metrics meet the required thresholds for moving forward.

**Q: How is reinjury risk calculated?**
Risk is assessed using `assess_reinjury_risk`, which evaluates the gap between biological healing and current functional capacity.
