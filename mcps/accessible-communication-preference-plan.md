## Description
This MCP server helps individuals manage their accessibility needs through structured communication planning. Use `get_user_communication_profile` to build a holistic summary of requirements, `generate_accommodation_request` to produce professional requests for organizations, and `create_contact_specific_plan` to provide tailored instructions for specific partners. It also includes `get_preference_review_workflow` to ensure accessibility settings remain current.


## Available Tools (4)
- **create_contact_specific_plan**: Generates a tailored guide for a specific person or group to follow when communicating with the user
- **generate_accommodation_request**: Produces a ready-to-send formal request for accommodations
- **get_preference_review_workflow**: Provides a structured set of questions or a schedule to help the user review and update their preferences
- **get_user_communication_profile**: Generates a holistic summary of the user's accessibility requirements

## ❓ FAQ

**Q: How do I create a formal request for an employer?**
You can use the `generate_accommodation_request` tool. Provide the profile data generated by `get_user_communication_profile`, the name of the organization, and the type of interaction (e.g., Interview).

**Q: Can I customize how much information I share?**
Yes. When using `get_user_communication_profile`, you can set the `consentLevel` to 'Minimal Disclosure' or 'No Disability Mention' to ensure your privacy is respected.

**Q: How can I ensure my communication preferences are up to date?**
Use the `get_preference_review_workflow` tool. It provides a structured checklist and calculates your next review date based on your preferred frequency.
