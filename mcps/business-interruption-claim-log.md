## Description
This MCP server provides a suite of forensic accounting tools to automate the generation of claim-ready audit logs. It bridges the gap between raw business disruption data and insurance requirements by using `get_claim_period_summary` to define indemnity windows, `reconcile_revenue_gap` to calculate lost income, and `calculate_extra_expenses` to aggregate disruption costs. Finally, `generate_claim_log` organizes all findings into a chronological, actionable ledger with specific collection actions for missing evidence.


## Available Tools (4)
- **generate_claim_log**: Aggregates all reconciled data into a final, actionable audit trail
- **get_claim_period_summary**: Determines the active window for a claim based on business disruption events
- **reconcile_revenue_gap**: Calculates the loss in income by comparing expected revenue against actual revenue
- **calculate_extra_expenses**: Identifies and aggregates costs incurred specifically due to the disruption

## ❓ FAQ

**Q: How does the tool determine the claim period?**
The `get_claim_period_summary` tool calculates the intersection between the actual business closure dates and the policy's indemnity period.

**Q: What is a collection action?**
A collection action is a specific instruction generated by `generate_claim_log` to retrieve missing evidence, such as a vendor receipt, needed to substantiate a claim entry.

**Q: Can I use this with Claude Desktop?**
