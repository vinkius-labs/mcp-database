## Description
This MCP server acts as a specialized auditor for construction and renovation projects. It compares contractor proposals against explicit checklists, property constraints, and the owner's desired finishes to identify omissions, decision conflicts, and regulatory violations. Use `identify_omitted_stages` to find missing work, `detect_decision_conflicts` to catch material mismatches, `check_property_constraints` to ensure compliance with building rules, `generate_clarification_requests` to resolve ambiguity, and `compose_scope_amendment` to create a formal contract addition.


## Available Tools (5)
- **check_property_constraints**: Flags any part of the contractor's scope that violates the physical or regulatory limits of the property
- **compose_scope_amendment**: Synthesizes all findings into a formal document ready for contract attachment
- **detect_decision_conflicts**: Identifies where the contractor's proposed method or material contradicts the owner's specific instructions
- **generate_clarification_requests**: Identifies ambiguous terms in the contractor's scope that prevent a reliable gap analysis
- **identify_omitted_stages**: Finds work stages required by the checklist that are absent from the contractor's scope

## ❓ FAQ

**Q: How does this tool identify missing work?**
It uses the `identify_omitted_stages` tool to compare the contractor's scope directly against your provided checklist. It only flags stages explicitly named in the checklist that are absent from the scope.

**Q: Can I use this to check if a contractor is using the wrong materials?**
Yes. By using `detect_decision_conflicts`, the agent compares the contractor's proposed materials against your specific `desiredFinish` requirements.

**Q: What is a scope amendment?**
An amendment is a formal document generated by `compose_scope_amendment` that bridges the gap between the current proposal and the required work, ready to be attached to a contract.
