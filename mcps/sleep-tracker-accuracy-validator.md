## Description
This MCP server provides a specialized validation engine to evaluate how accurately consumer sleep trackers report sleep data. By comparing device metrics against clinical standards like polysomnography, it calculates core accuracy and bias using `get_validation_metrics`. It also evaluates how physical positioning affects data quality via `assess_placement_impact`, generates a unified confidence score with `calculate_reliability_score`, and provides historical performance profiles through `compare_device_performance`.


## Available Tools (4)
- **calculate_reliability_score**: Generates a single, unified confidence score for the tracker performance
- **assess_placement_impact**: Adjusts the reliability of the data based on how the device was worn
- **compare_device_performance**: Evaluates how a specific device type performs across different user configurations
- **get_validation_metrics**: Calculates core accuracy and bias metrics between a tracker and a reference method

## ❓ FAQ

**Q: How is sleep accuracy determined?**
Accuracy is determined by using `get_validation_metrics` to compare the tracker's reported sleep duration and stages against a reference method like polysomnography.

**Q: Can I check if my device placement is affecting the results?**
Yes, you can use `assess_placement_impact` to evaluate how the physical positioning of your device affects signal quality and reliability.

**Q: What is a reliability score?**
A reliability score is a composite value generated by `calculate_reliability_score` that weights accuracy and signal stability to show how much you can trust the device.
