## Description
This MCP server provides precise tools for enologists to manage protein stability in wine. By using the `calculate_minimum_dose` tool, users can determine the exact amount of bentonite required based on instability scores and wine volume. The server also includes `estimate_lees_impact` to predict sediment volume and wine loss, `recommend_treatment_mode` to choose between batch or in-line processing, and `validate_bentonite_compatibility` to ensure the selected clay matches the wine's specific needs.


## Available Tools (4)
- **recommend_treatment_mode**: Advises whether the treatment should be performed in a single batch or through an in-line system
- **calculate_minimum_dose**: Determines the lowest amount of bentonite needed to achieve stability based on instability test results
- **estimate_lees_impact**: Predicts the physical consequences of the bentonite treatment on the cellar
- **validate_bentonite_compatibility**: Checks if a specific bentonite type is suitable for the current instability profile and risk constraints

## ❓ FAQ

**Q: How does this tool help prevent overfining?**
The `calculate_minimum_dose` tool incorporates a risk tolerance parameter, allowing you to adjust the dosage to avoid stripping desirable proteins and flavors.

**Q: Can I predict how much wine I will lose during treatment?**
Yes, by using the `estimate_lees_impact` tool, you can calculate the estimated wine loss resulting from the volume of lees generated by your bentonite dose.

**Q: What is the difference between batch and in-line treatment?**
The `recommend_treatment_mode` tool advises whether to use batch treatment for smaller volumes or in-line treatment for large volumes requiring high precision.
