## Description
This MCP server manages the redistribution of costs incurred during vehicle trips. It allows AI agents to calculate total trip costs using `calculate_trip_totals`, distribute those costs among drivers and riders via `allocate_participant_costs`, and identify the most efficient way to settle debts using `generate_settlement_plan`. It also includes `validate_trip_metadata` to ensure trip data is logically consistent before processing.


## Available Tools (4)
- **allocate_participant_costs**: Distributes the total trip cost among all participants based on specific rules
- **calculate_trip_totals**: Aggregates all raw trip data into a single total cost figure
- **generate_settlement_plan**: Identifies the specific transfers needed to zero out all participant balances
- **validate_trip_metadata**: Ensures the trip details provided are logically consistent before processing

## ❓ FAQ

**Q: How are trip costs calculated?**
Costs are aggregated using the `calculate_trip_totals` tool, which sums fuel expenses and usage fees.

**Q: Can I use custom split rules?**
Yes, the `allocate_participant_costs` tool supports both equal splits and weighted splits based on user-provided weights.

**Q: What is a settlement plan?**
A settlement plan is a list of the minimum number of transfers required to zero out all participant balances, generated by `generate_settlement_plan`.
