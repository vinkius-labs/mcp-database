## Description
This MCP server provides tools to manage tournament registration data. You can use `calculate_revenue` to determine gross revenue based on confirmed teams and fees, `get_team_count` to track participant numbers, `get_tournament_details` to retrieve configuration like category and current fees, and `validate_registration_eligibility` to check if a team can join a tournament.


## Available Tools (4)
- **calculate_revenue**: Determine the total revenue generated by a specific tournament based on its registration data
- **get_team_count**: You can optionally include cancelled registrations.

Count how many teams are currently registered for a given tournament
- **get_tournament_details**: Retrieve the basic configuration and current registration status of a tournament
- **validate_registration_eligibility**: Check if a specific team is allowed to register for a tournament based on its current status

## ❓ FAQ

**Q: How is revenue calculated?**
Revenue is calculated by multiplying the number of confirmed teams by the specific fee per team using the `calculate_revenue` tool.

**Q: Can I include cancelled registrations in the team count?**
Yes, the `get_team_count` tool allows you to optionally include teams with a cancelled status.

**Q: How do I check if a team is eligible to register?**
You can use the `validate_registration_eligibility` tool to verify if a team meets all requirements for a specific tournament.
