## Overview

**Category:** [finance](../categories/finance.md)

Splits shared travel expenses equally among a group of companions.

## Description
This MCP server provides a precise calculation engine for dividing shared travel costs. It allows AI agents to manage group finances by calculating total expenditures, individual target shares, and net balances. Use `get_expense_summary` to see the total group cost, `get_companion_balances` to check who owes or is owed money, and `calculate_settlement_plan` to generate a minimal list of transactions to settle all debts.


## Available Tools (4)
- **calculate_settlement_plan**: Generates a minimal list of transactions required to settle all debts within the group
- **get_companion_balances**: Determines exactly how much each person has contributed and their resulting financial position
- **get_expense_summary**: Provides a high-level overview of the total group expenditure and the individual target share
- **validate_group_integrity**: Verifies that the provided list of companions is valid for a calculation

## ❓ FAQ

**Q: How does the tool calculate the split?**
The tool divides the total group expense by the number of companions to determine an equal target share for everyone.

**Q: What is a settlement plan?**
A settlement plan is a minimal list of transactions generated by `calculate_settlement_plan` to ensure everyone's net balance reaches zero.

**Q: Can I use this for large groups?**
Yes, the engine is designed to handle any number of companions and calculate their individual balances and settlement needs.
