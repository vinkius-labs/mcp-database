Analyze customer cohort behavior through retention curves, LTV, and decay rates.

## Description
This MCP server provides deep insights into customer lifecycle behavior. Use `get_retention_curve` to visualize how engagement diminishes over time, `calculate_cohort_ltv` to determine the total economic value of a group, and `analyze_decay_rate` to measure the velocity of user churn. It also includes `get_seasonal_adjustment_factor` to normalize data against seasonal fluctuations, helping you understand if a cohort has reached a steady state.


## Available Tools (4)
- **analyze_decay_rate**: Measure the velocity of user churn within a cohort
- **get_retention_curve**: Understand how quickly a specific cohort's engagement diminishes over time
- **get_seasonal_adjustment_factor**: Provide a multiplier that accounts for expected behavioral shifts due to the time of year
- **calculate_cohort_ltv**: Determine the total economic value generated by a specific group of users

## ❓ FAQ

**Q: How do I see the retention curve for a specific group?**
You can use the `get_retention_curve` tool by providing the specific cohort ID and the desired period type, such as monthly.

**Q: Can I calculate the lifetime value of a cohort?**
Yes, the `calculate_cohort_ltv` tool calculates the total economic value generated by a cohort based on its initial size and cumulative revenue.

**Q: How is the decay rate determined?**
The `analyze_decay_rate` tool measures the velocity of churn. It identifies if a cohort has stabilized if the change in retention rate falls below a threshold over recent periods.

5. Click the **+** button in any chat and enable **Cohort Analysis** under Connectors.

### Cursor
Follow the steps below to connect in seconds.

1. In Cursor, open Settings (`⌘ ,`) → scroll to **Features** → **MCP Servers**.
2. Click **+ Add new MCP Server**.
3. Set Type to "SSE" (or "streamable HTTP"), enter `cohort-analysis` as the name, and paste the MCP server link (`https://edge.vinkius.com/[TOKEN]/mcp`).
4. Click **Save** — Cursor will connect and list all **Cohort Analysis** tools.

**Configuration:**
```json
{

      "url": "https://edge.vinkius.com/[TOKEN]/mcp"
```
