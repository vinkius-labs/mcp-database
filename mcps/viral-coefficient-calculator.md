## Description
This MCP server provides essential tools for analyzing product growth dynamics. Use `calculate_viral_k` to determine the fundamental viral coefficient, `calculate_growth_multiplier` to estimate user base expansion, and `estimate_time_to_scale` to predict the duration needed to reach specific user targets. It also includes `analyze_saturation_impact` to account for market availability and diminishing returns as the user base grows.


## Available Tools (4)
- **analyze_saturation_impact**: Adjusts growth expectations based on market availability
- **calculate_growth_multiplier**: Estimates the total expansion of the user base relative to the initial cohort
- **calculate_viral_k**: Determines the fundamental viral coefficient for a user cohort
- **estimate_time_to_scale**: Predicts how long it will take to reach a specific user target

## ❓ FAQ

**Q: What is the viral coefficient?**
The viral coefficient (K) represents the number of new users generated by each existing user. You can find this value using the `calculate_viral_k` tool.

**Q: How do I predict when my product will reach a certain size?**
You can use the `estimate_time_to_scale` tool by providing your initial user count, target user count, current viral coefficient, and the length of your growth cycle.

**Q: Does this tool account for market saturation?**
Yes, the `analyze_saturation_impact` tool adjusts your growth expectations based on the current number of users relative to the total addressable market.
