## Description
This MCP server provides specialized tools for resistance training intensity techniques. It allows users to determine the exact weight and repetition profile for every stage of a drop set sequence using `calculate_drop_set_structure`. Beyond weight planning, it quantifies the training stimulus by using `evaluate_volume_impact` to measure workload increases and `estimate_metabolic_stress` to assess the physiological demand. Finally, `get_training_parameters_summary` consolidates all metrics into a single, actionable report for lifters looking to optimize hypertrophy and metabolic stress.


## Available Tools (4)
- **calculate_drop_set_structure**: Determines the specific weight and repetition profile for every stage of a drop set sequence
- **estimate_metabolic_stress**: Provides a qualitative and quantitative estimate of the metabolic stimulus produced
- **evaluate_volume_impact**: Quantifies the total additional workload generated by performing the drop set
- **get_training_parameters_summary**: Consolidates all calculated data into a single comprehensive report

## ❓ FAQ

**Q: How do I calculate the weight for each drop?**
You can use the `calculate_drop_set_structure` tool by providing your starting weight, target reps, the percentage you want to drop, and the number of drops.

**Q: Can I see the total volume increase from my drop set?**
Yes, the `evaluate_volume_impact` tool calculates the total additional workload compared to a standard set.

**Q: What is metabolic stress?**
Metabolic stress is a driver of muscle growth caused by metabolite accumulation. You can estimate this using the `estimate_metabolic_stress` tool.
